# 種族ごとの特性 — v53

全259種に固定の特性を1つずつ設定する。公開図鑑の256種に加え、非公開のヌルミィ・ヌルヴァ・ゼロヴェイルも対象。正本は `data/species-abilities.json`。個体データに特性を保存せず、種族IDから引くため、すでに仲間になっている個体にも同じ特性が適用される。

## 割り当ての考え方

タイプだけで一律に決めず、姿、図鑑の説明、進化系統、基礎能力、実際に使える4つの技を照合した。多くの進化系統は同じ特性を継承する。御三家は各タイプのピンチ火力、甲殻・金属の種族は物理軽減、月や航路を読む種族は命中補助、庭・森・珊瑚を育てる種族は条件付き回復を中心にしている。

| 種族・系統 | 特性 | 選定理由 |
| --- | --- | --- |
| コモリ → コモリオン → コモリゼン | 芽吹きの底力 | 芽の技を物理・特殊とも支え、進化後の専用技にも有効。 |
| シズク → シズルア → シズナリア | 深潮の息吹 | 潮の流れを操る系統。体力1/3以下でのみ火力が上がる。 |
| ヒバナ → アケビノ → アケホムラ | 残り火の誓い | 尾に守る灯と夜明けの案内役という性格に合わせる。 |
| クロト → ヨルツキ | 道しるべの瞳 | 暗闇の測量士という説明から命中を補助。 |
| ココロク | やすらぎの息 | 薬草を育て旅人を見守る姿。回復は半分以下・最大体力の1/32に限定。 |
| アルヴェリオン | 残り火の誓い | 伝説の灯の獅子に合わせる。高い基礎能力や全能力強化へ常時補正を重ねない。 |
| フート | 揺るがぬ芯 | カスタム可能な攻撃・技のどの組み合わせでも役立つ。急所の追加分だけを防ぐ。 |
| キラシード | じっくり力 | 低い素早さを活かす。元の高体力・高耐久への追加防御や再生は付けない。 |
| ヌルミィ → ヌルヴァ → ゼロヴェイル | 影読み | 自分で使う呪縛・灯焼けと連動。無タイプの全状態異常耐性に重複しない。 |

ヴェロハ・ヴェロシカは吸収技を持つため「いのちの巡り」。吸収技を失うヴェロクレスは、潮の技を活かす「旅の知恵」に変わる。ヴェミルは「剛腕の拍子」、貫通技を覚えるヴェルミオ・ヴェルミレドは「針先の心得」。これらも種族ごとの固定割り当てであり、抽選や隠れ特性はない。

## 判定と互換性

- 攻撃・防御の倍率は攻撃技の直接ダメージにのみ適用する。花毒、灯焼け、呪縛、反動のダメージは対象外。
- 「旅の知恵」はどちらのタイプとも一致しない攻撃技が対象。タイプのない攻撃技も一致しない扱いとする。
- 「じっくり力」は技を当てる時点の両者の実効素早さを比較する。同速、先手の爪、優先行動だけでは発動しない。
- 「虹の受け流し」は複合タイプを計算した最終相性が1より大きい場合に適用する。
- 「いのちの巡り」は吸収攻撃の回復分のみ対象。持ち物の吸命、回復技、ターン末回復にはかからない。
- 「ひと粒の備え」はターン末に生存していて条件を満たすと1バトルにつき1回。交代で回数を補充しない。
- 満タン時の軽減は、その一撃を受ける直前の体力で判定する。再び満タンになれば有効。
- 状態予防は該当状態の新たな付与だけを防ぎ、付与済みの状態は自動で治さない。呪縛の予防にはならない。同じタイプですでに防ぐ状態を割り当てていない。
- 戦闘不能の個体を回復せず、最大体力を超えない。体力の小さい個体にも効果があるよう回復量は最低1。
- 特性IDを個体保存や通信入力から信用せず、種族のカタログを正とする。進化後は進化先の特性を引く。

## カタログ確認

259種のIDが過不足なく一度ずつ存在し、28特性すべてに割り当てがあることを確認した。攻撃カテゴリ・小技・不一致技・貫通技・回復技・吸収技を条件にする特性は、各種族の初期技に対象がある。状態予防5種は、種族の単/複合タイプの既存耐性と重複しない。

完成したカタログをv53の種族データから独立に読み直して照合し、不足・余分なID・機能しない技条件は0件だった。131本の進化関係のうち129本は同じ特性を継承し、変更する2本は上記の技構成に対応する。割り当ては1特性あたり2〜19種、最多でも全体の7.34%。芽・潮はそれぞれ16種類、灯は15種類、風は14種類、晶・土はそれぞれ12種類、氷・雷はそれぞれ5種類の特性を持つ。無3種は同一系統として「影読み」を共有する。

レア種の出現条件・配布条件・専用技・反動・初期レベル、キラシードの管理者限定、無3種の非公開図鑑と全状態異常耐性は、このカタログでは変更しない。特性は種族の既存設定に追加する効果として定義した。
