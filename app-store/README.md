# App Store提出用の日本語下書き

このフォルダーはApp Store Connectへ入力する候補文章と確認事項です。自動アップロード用API payloadではありません。内容の確定、Appleアプリレコードへの入力、審査提出はまだ行っていません。

- `ja-JP/`: アプリ名・サブタイトル・説明・キーワード・初版更新説明。
- `submission-draft.json`: 既定Bundle ID・バージョンと未確定項目。
- `review-notes-ja.md`: App Reviewへ伝える操作説明の候補。
- `privacy-age-rating-draft.md`: 実装から分かるデータ処理と、所有者が確定すべき回答。
- スクリーンショット: 未作成。実際のiOSアプリを起動して撮影します。Web版の画像を実機確認済みの証拠として扱いません。

公開privacy/supportの想定URLはGitHub Pagesの公開更新後に確認してください。本番通信サーバーのアカウント削除更新は別途必要です。

作業手順は `../docs/APP_STORE_JA.md`、実施記録は `../docs/APP_STORE_RELEASE_CHECKS.md` を参照してください。
